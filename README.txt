   🌱 مشروع المزرعة الذكية - Farm IoT Dashboard
═══════════════════════════════════════════════════════════════

أهلاً بك! تم تبسيط المشروع ليكون سهل الاستخدام جداً.
لديك الآن ملفين فقط للتحكم في كل شيء:

1️⃣ التشغيل (START_PROJECT.bat)
   - اضغط عليه مرتين لتشغيل المشروع.
   - سيقوم بتنظيف القديم، وتشغيل الجديد، وفتح الموقع تلقائياً.

2️⃣ الإيقاف (STOP_PROJECT.bat)
   - اضغط عليه عندما تنتهي لإيقاف المشروع.

═══════════════════════════════════════════════════════════════
🌐 روابط الدخول
═══════════════════════════════════════════════════════════════

🎨 لوحة التحكم (Dashboard):
   http://localhost:3000
   (تفتح تلقائياً، وفيها الشات بوت والرسوم البيانية)

📈 جرافانا (Grafana):
   http://localhost:3001
   (يمكن فتحه من داخل لوحة التحكم أيضاً)
   - اسم المستخدم: admin
   - كلمة المرور: admin

═══════════════════════════════════════════════════════════════
❓ حل مشاكل سريعة
═══════════════════════════════════════════════════════════════

❌ الموقع لا يفتح؟
   - تأكد أن Docker Desktop يعمل.
   - انتظر دقيقة بعد التشغيل حتى تعمل جميع الخدمات.
   - جرب تحديث الصفحة (F5).

❌ جرافانا يطلب تسجيل دخول داخل الموقع؟
   - تم تفعيل الدخول التلقائي، لكن إذا طلب، استخدم admin/admin.
   - إذا ظهرت شاشة بيضاء، جرب فتح الرابط المباشر: http://localhost:3001

❌ البيانات لا تظهر؟
   - تأكد أن الـ Producer يعمل (شاهد الشاشة السوداء الخاصة بـ Docker).
   - انتظر 30 ثانية لتدفق البيانات.
